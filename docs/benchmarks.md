**New physical measurements:** No

**Limits:** Completion checks require distinctive visible screens, biasing tasks toward immediate visual feedback. Evaluation termination signals success and supplies no failure termination signal. Prior game knowledge can contaminate results; knowledge checks do not establish complete absence of contamination. The games evaluate embodied gameplay rather than executed scientific research experiments.

Evaluation uses task-specific binary completion functions based on screen-reference matching, task completion gain, and playthrough progress markers; these completion functions are distinct from training rewards. |
| Reset | Page 14 establishes exact reset: every episode loads a complete emulator save-state snapshot, and resetting restores it exactly. Page 19 specifies budgets of 1000 CI tests, 60 turns, 16000 output tokens per turn, 2400 seconds and 12 algorithm-menu calls. Analysis code sees the data but neither ground truth nor harness state. The code tool uses a child process with a cleaned environment; page 9 states that it is not a security sandbox.
