<summary>Benchmarking and Enhancing Agentic Causal Discovery — details</summary>

[Work](../README.md#paper-13a316d3fa2ce54f) · [Source](https://arxiv.org/pdf/2610.22846)

**Focus:** HEURESIS evaluates causal graph discovery through executed statistical and numerical investigations of fixed observational tables generated from hidden synthetic SCMs. Agents run discovery algorithms, request conditional-independence tests and resampling diagnostics, execute numpy/scipy analysis, and edit and submit graphs. Tool results provide evidence; hidden ground truth is reserved for scoring. These are computational experiments on simulated data, with no new physical measurements.

**Openness:** `Pages 1 and 9 promise public code and data releases.`, `Page 9 specifies MIT licensing for code and CC BY 4.0 for data.`, `Page 12 describes frozen development instances as public and test seeds as sealed and rotated.`, `Release availability is not independently established by the supplied pages.`

**New physical measurements:** No

**Limits:** All instances use simulated continuous data with 10 variables and 600 observations across six mechanism families. Real-data transfer remains untested. Page 19 specifies budgets of 1000 CI tests, 60 turns, 16000 output tokens per turn, 2400 seconds and 12 algorithm-menu calls. Analysis code sees the data but neither ground truth nor harness state. The code tool uses a child process with a cleaned environment; page 9 states that it is not a security sandbox.
